# ProrubPetersburg
Итоговый проект для курса "Нарративный дизайн" в DH-магистратуре ИТМО, 2025

### Инструкция по запуску:
1. нажмите "Code" в правом верхнем углу
2. нажмите "Download ZIP" (скачать ZIP)
3. откройте скачавшуюся папку и запустите файл index.html в своём браузере
